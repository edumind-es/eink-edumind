# E-ink EDUmind

Sistema de estilos CSS optimizado para lectura en pantallas e-ink y en papel,
pensado para recursos educativos: alto contraste, tipografía hiperlegible y
componentes imprimibles.

## Contenido

- `eink.css` — sistema completo
- `eink-essentials.css` — subconjunto mínimo
- `eink-max.css` — variante de máximo contraste
- `eink-sistema-v2.html` / `eink-max-demo.html` — demos autocontenidas
- `EINK-GUIA.md` — guía de uso con ejemplos

## Uso

```html
<link rel="stylesheet" href="eink.css">
```

Ver `EINK-GUIA.md` para los componentes disponibles.

## Tipografías incluidas

- **Atkinson Hyperlegible** (Braille Institute) — SIL Open Font License 1.1
- **Literata** (TypeTogether / Google Fonts) — SIL Open Font License 1.1
